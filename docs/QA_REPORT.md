## Final User Check

Speech recognition varies with microphone quality, room noise, accent, and specialized vocabulary. Before a public release, perform a short real-microphone acceptance pass in Notepad and the user's main writing applications. Test the global hotkey, custom vocabulary, Developer mode, undo, real third-party chat, and an explicitly approved elevated target. Human-review the style, summary, and multilingual writing cases. These hardware, access-boundary, language-quality, and real-application checks cannot be proven by offscreen automation alone.
